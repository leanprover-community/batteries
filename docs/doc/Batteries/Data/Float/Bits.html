    Bit-level utilities for Float and Float32 #

    Classification, sign manipulation and neighbor functions from IEEE 754-2019 §5.3.1, §5.5.1 and §5.7.2, together with unit in the last place and distance in units in the last place.

    All functions are defined in terms of toBits and ofBits and check for NaN first. The logical model of Lean's floats has a single canonical NaN, while compiled code may see any NaN bit pattern, so this keeps the compiled behavior in line with the model. As a consequence, NaN has no sign here: signBit nan = false, and copySign x nan is x with a positive sign.

    inductive Float.Category :
    Type

    The class of a floating-point number, following IEEE 754-2019 §5.7.2.

    • nan : Category

      Not a number.

    • infinite : Category

      Positive or negative infinity.

    • zero : Category

      Positive or negative zero.

    • subnormal : Category

      A nonzero number whose exponent field is zero.

    • normal : Category

      A finite number whose exponent field is not zero.

                            def Float.ulp (x : Float) :
                            Float

                            The unit in the last place of x: the distance from |x| to the next number of larger magnitude. For the largest finite number, it is the distance to the next number of smaller magnitude. This agrees with Julia's eps(x).

                            Special cases: ulp 0 is the smallest positive subnormal number, and ulp x = nan when x is infinite or NaN.

                              The position of x on the number line that counts floating-point numbers, with both zeros at 0, positive numbers at their bit pattern and negative numbers at the negation of the bit pattern of their absolute value.
