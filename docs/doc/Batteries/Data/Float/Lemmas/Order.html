    Order lemmas for Float and Float32 #

    The lemmas are proved through the logical models Float.Model and Float32.Model. The order is the IEEE 754 partial order, in which NaN is incomparable with everything and -0 = +0.

    compare s t = match s, t with | negative, positive => Ordering.lt | positive, negative => Ordering.gt | x, x_1 => Ordering.eq
