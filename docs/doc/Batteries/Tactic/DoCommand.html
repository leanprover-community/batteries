    The #do command #

    The #do command is like run_cmd but allows using variables from previous uses of #do. Furthermore, #do_meta is like #do and shares its variable state while operating in MetaM. Finally, #clear_do can be used to remove all variables from the current do state.

                          #do code runs code with access to all variables from previous #do (and #do_meta) invocations. Example:

                          #do let x ← IO.rand 0 100
-- these will both print the same number
#do IO.println x
#do IO.println x

                          This command can be used to run expensive computations once and refer to them later.

                          For #do, the body is run in the CommandElabM monad. For an alternative where computations run in MetaM, use #do_meta.
