    The frame closure #

    The frame closure is an endomap on predicate transformers over a family of supremum-preserving operators op r, one per resource r. It internalizes the frame rule into the transformer it is applied to. The companion family opE r frames the exception postcondition; the FrameOp class relates op to its companion, derived by the structure of the exception postcondition type.

    source
    class Lean.Order.FrameOp {Pred : Type u} [CompleteLattice Pred] {R : Type x} (op : R → Pred → Pred) (EPosts : Type v) [CompleteLattice EPosts] (opE : outParam (R → EPosts → EPosts)) :
    Prop

    Relates a frame operator op on the value channel of a PredTrans Pred EPosts to a companion opE on the exception channel. Both preserve suprema. Instances derive opE from the structure of EPosts: op itself on the assertion type, a pointwise lift under a function layer, and a componentwise lift on a product layer. A low-priority default instance ignores the frame. An instance for a custom exception layer takes precedence.

    • preservesSup (r : R) : PreservesSup (op r)

      Each op r preserves suprema, so it has an upper adjoint.

    • preservesSupE (r : R) : PreservesSup (opE r)

      Each opE r preserves suprema, so it has an upper adjoint.

            noncomputable def Lean.Order.PredTrans.frameClosure {Pred : Type u} [CompleteLattice Pred] {EPosts : Type v} [CompleteLattice EPosts] {β : Type w} {R : Type x} {opE : R → EPosts → EPosts} (op : R → Pred → Pred) [FrameOp op EPosts opE] (t : PredTrans Pred EPosts β) :
            PredTrans Pred EPosts β

            The frame closure of a predicate transformer t with respect to a family of supremum-preserving operators op r and its exception-channel companion opE r: the meet over all resources r of the r-upper-adjoint of t framed by r on both channels. It internalizes the frame rule into any t (see PredTrans.frameClosure_frames), with no assumption on t.
