    Predicate transformers #

    PredTrans Pred EPosts α wraps a map from a normal postcondition α → Pred and an exception postcondition EPosts to a precondition Pred. The order and the chain-complete suprema are the pointwise ones of the function space.

    PredTrans Pred EPosts is a monad, so monadic programs can be interpreted by a monad morphism into it. This module provides that monad structure, the apply computation rules of the monadic combinators, the push family that moves a result type into a postcondition, and the standard monad class instances.

    structure Lean.Order.PredTrans (Pred : Type u) (EPosts : Type v) (α : Type w) :
    Type (max (max u v) w)

    A predicate transformer from postconditions to preconditions.

    Given a return type α, a lattice Pred for assertions, and an exception assertion type EPosts, PredTrans Pred EPosts α wraps a function (α → Pred) → EPosts → Pred.

    • apply : (α → Pred) → EPosts → Pred

      Apply the predicate transformer to a postcondition and exception postcondition.
