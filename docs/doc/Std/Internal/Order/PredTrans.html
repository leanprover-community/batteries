    Predicate transformers #

    PredTrans Pred EPosts α wraps a map from a normal postcondition α → Pred and an exception postcondition EPosts to a precondition Pred. The order and the chain-complete suprema are the pointwise ones of the function space.

    PredTrans Pred EPosts is a monad, so monadic programs can be interpreted by a monad morphism into it. This module provides that monad structure, the apply computation rules of the monadic combinators, the push family that moves a result type into a postcondition, and the standard monad class instances.

    source
    structure Lean.Order.PredTrans (Pred : Type u) (EPosts : Type v) [PartialOrder Pred] [PartialOrder EPosts] (α : Type w) :
    Type (max (max u v) w)

    PredTrans Pred EPosts α is the type of monotone predicate transformers with result type α, over an ordered type Pred of assertions and an ordered type EPosts of exception postconditions. PredTrans.apply : PredTrans Pred EPosts α → (α → Pred) → EPosts → Pred runs the predicate transformer, and PredTrans.apply_mono proves that it is monotone in both ordered arguments. PredTrans.mk constructs predicate transformers. The definition of PredTrans.apply is opaque, for the efficiency of kernel reduction.
