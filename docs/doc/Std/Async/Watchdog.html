    structure Std.Async.Watchdog :
    Type

    Enforces deadlines on a sequence of waits with a single background timer. A wait starts with arm and ends with disarm; when one outlives its deadline, the watchdog cancels its context with .deadline and stops. The context is never cancelled before the deadline.

    Waits whose deadlines keep moving later, such as idle timeouts, cost no timer operation each: only a deadline earlier than the one the timer is set for restarts it.

    The context is cancelled from a task on the shared task pool, so while every worker is busy, a late wait may stay uncancelled until one is free. disarm reports a late wait regardless.

    The watchdog and its timer stay alive until the context is cancelled, so the context should be cancelled once the watchdog is no longer needed.

              def Std.Async.Watchdog.disarm (wd : Watchdog) :
              BaseIO Bool

              Ends the current wait. Returns true if a wait outlived its deadline, in which case the context is cancelled with .deadline. A wait whose context was cancelled for another reason first is not reported.
