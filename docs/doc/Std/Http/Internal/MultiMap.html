    MultiMap #

    This module defines a generic MultiMap type that maps keys to multiple values while remembering the order in which entries were inserted.

    Entries live in one array and lookups scan it. Header maps hold at most a few dozen entries and see a handful of lookups per message, so a scan costs less than maintaining any index on insert.

    source
    structure Std.Internal.MultiMap (α : Type u) (β : Type v) :
    Type (max u v)

    A structure for managing ordered key-value pairs where each key can have multiple values.

    • entries : Array (α × β)

      All key-value entries in insertion order.
