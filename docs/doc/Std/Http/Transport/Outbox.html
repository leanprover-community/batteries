    Outbox #

    An Outbox writes a connection's output to its transport in order, without the connection waiting for each write.

    source
    structure Std.Http.Internal.Outbox.State :
    Type

    The state of an Outbox.

    • queued : List (Array ByteArray)

      Output handed over while a write was in flight, newest first, written together once it completes. A list, because the state is shared with the thread that completes the write, so an array here would be copied on every append.

    • queuedBytes : Nat

      The size of queued in bytes.

    • writing : Bool

      A write is in flight.

    • failed : Bool

      A write failed, so later output is dropped.

    • error : Option IO.Error

      The error of the failed write, until it is taken.

    • idle : Option (IO.Promise Unit)

      Resolved once no write is in flight.

    • idleSince : Nat

      When the last write completed, by IO.monoMsNow.

    • progressAt : Nat

      When a write last started with none in flight or completed, by IO.monoMsNow.

      structure Std.Http.Internal.Outbox (α : Type) :
      Type

      Writes a connection's output to socket in order without the connection waiting for it. At most one write is in flight. Output handed over meanwhile goes out in a single write once that write completes, started by the thread that completed it.

      • socket : α

        The transport the output is written to.

      • writeTimeout : Nat

        How long, in milliseconds, a wait for output to be written lasts without any write completing before the outbox fails.

      • state : IO.Ref Std.Http.Internal.Outbox.State
