    Automation for measures #

    This module registers the automation lemmas of NondetFun.EvalsTo, Variant.EvalsTo and Variant.EvalsBelow with simp and grind norm, by the criterion of Std.Internal.Order.Automation. For example, at carrier Nat → Prop and the measure f := fun (x : Nat × Nat) => (x.1, x.2), the decrease (Variant.ofMeasure f).EvalsBelow (i, j) m s rewrites to i < m.1 ∨ i = m.1 ∧ j < m.2.
