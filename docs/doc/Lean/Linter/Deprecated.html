                inductive Lean.Linter.DeprecationHint :
                Type

                How a deprecation warning for a constant with a replacement suggests switching to the replacement. Suggestions are only made when the replacement has the same type as the deprecated constant.

                • none : DeprecationHint

                  No suggestion.

                • ident : DeprecationHint

                  If the current ref is an identifier that resolves to the deprecated constant, offers to replace it with the shortest name that resolves to the replacement.

                • custom (mk : Name → MetaM MessageData) : DeprecationHint

                  Appends the message computed from the name of the replacement, such as a hint for syntax other than a plain identifier, or a note explaining why no hint is offered.
