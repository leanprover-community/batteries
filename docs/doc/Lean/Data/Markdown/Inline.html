                                    inductive Lean.Markdown.Inline (s : String.Slice) :
                                    Type

                                    A parsed inline element of the source string s.

                                    • text {s : String.Slice} (range : s.Subslice) : Inline s

                                      Plain text.

                                    • code {s : String.Slice} (openTicks : s.Subslice) (content : InlineCodeContent s) (closeTicks : s.Subslice) : Inline s

                                      Inline code (CommonMark §6.1).

                                    • italic {s : String.Slice} (openDelim : s.Subslice) (content : Array (Inline s)) (closeDelim : s.Subslice) : Inline s

                                      Italic emphasis.

                                    • bold {s : String.Slice} (openDelim : s.Subslice) (content : Array (Inline s)) (closeDelim : s.Subslice) : Inline s

                                      Bold/strong emphasis.

                                    • link {s : String.Slice} (openBracket : s.Subslice) (text : Array (Inline s)) (closeBracket : s.Subslice) (target : LinkTarget s) : Inline s

                                      Inline or reference link. The text is recursively parsed.

                                    • image {s : String.Slice} (bang openBracket : s.Subslice) (alt : Array (Inline s)) (closeBracket : s.Subslice) (target : LinkTarget s) : Inline s

                                      An image. The alt content is recursively parsed as inline content (CommonMark §6.4); HTML rendering should flatten it to plain text for the alt attribute.

                                    • hardBreak {s : String.Slice} (marker newline : s.Subslice) : Inline s

                                      A hard line break (CommonMark §6.7). marker is the backslash or the two or more trailing spaces that make the line ending a hard break, and newline is the line ending.

                                    • autolink {s : String.Slice} (openAngle url closeAngle : s.Subslice) (isEmail : Bool) : Inline s

                                      An autolink, which is <https://...> or <scheme:...> for URI form, or <user@domain> for email form (CommonMark §6.5). The URL between the angle brackets is verbatim. Backslash escapes, character references, and other Markdown syntax are not processed inside it. isEmail distinguishes the email form, whose href gets a mailto: prefix when rendered to HTML.

                                    • math {s : String.Slice} (openDollars : s.Subslice) (content : MathContent s) (closeDollars : s.Subslice) (display : Bool) : Inline s

                                      LaTeX math, produced only when the latexMath extension is enabled.

                                      This extension uses $…$ for inline math and $$…$$ for display math, with display set to true for the latter.

                                    • html {s : String.Slice} (lines : Lines s) : Inline s

                                      Raw HTML (CommonMark §6.6), which is an open or closing tag, a comment, a processing instruction, a declaration, or a CDATA section. The HTML is stored verbatim.

                                    • softBreak {s : String.Slice} (range : s.Subslice) : Inline s

                                      A soft line break (CommonMark §6.8), which is the line ending between two lines of a paragraph.

                                    • escape {s : String.Slice} (backslash char : s.Subslice) : Inline s

                                      A backslash escape \X of an ASCII punctuation character (CommonMark §2.4). backslash is the \ and char is X, which is the text the escape denotes.

                                    • entity {s : String.Slice} (range : s.Subslice) (value : String) : Inline s

                                      A character reference such as &amp;, &#35;, or &#x1F600; (CommonMark §2.5). The subslice extends from & through ;. value is the text that the entity denotes.

                                                      structure Lean.Markdown.LinkLabel :
                                                      Type

                                                      A normalized link label.

                                                      According to the CommonMark spec §4.7, link labels are normalized as follows:

                                                      • They are case-folded (though this implementation does not implement full Unicode case folding)
                                                      • Internal whitespace is collapsed to a single space
                                                      • Leading and trailing whitespace are removed

                                                      The constructor is private. Build values via normalizeLabel.

                                                      • name : String

                                                        The label's text after normalization.

                                                        Normalization consists of case folding, collapsing internal whitespace to single spaces, and trimming leading and trailing whitespace.

                                                              def Lean.Markdown.normalizeLabel {s : String.Slice} (lines : Lines s) :
                                                              LinkLabel

                                                              Normalizes a CommonMark link label (§6.3). lines are the label's source lines, and each boundary between two lines counts as whitespace. Then:

                                                              • Each character is case folded with caseFold, which covers ASCII, Latin-1, and Greek.
                                                              • Internal sequences of whitespace become single spaces.
