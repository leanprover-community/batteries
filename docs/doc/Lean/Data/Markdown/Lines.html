          structure Lean.Markdown.Lines (s : String.Slice) :
          Type

          The text of a construct that may span source lines, as one subslice per line.

          The lines are in source order and are nonempty. The subslices exclude line endings and the prefixes of enclosing containers.

          • toArray : Array s.Subslice

            The subslices, one per source line, in source order.

          • nonempty : 0 < self.toArray.size

            There is at least one line.
