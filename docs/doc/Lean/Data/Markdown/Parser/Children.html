    Container Children #

    The children of a container while the block structure is being parsed. A list whose last item has closed may still receive another item, so it is kept apart from the finished blocks until the next line, which determines whether it continues. The constructor of Children is private to protect invariants. Because push is the only operation that appends a block, and it finishes the pending list first, a block never ends up before the list that precedes it.

        structure Lean.Markdown.Children (s : String.Slice) :
        Type

        The closed children of a container, in source order.

        When a list item closes, its list is not finished. The next line that begins with a marker of the same kind adds another item to it. While still open, the list is saved in pendingList?. It becomes the last element of blocks when closed.

        • blocks : Array (Block.Raw s)

          The finished blocks.

        • pendingList? : Option (OpenList s)

          The list that is the last child so far and may still receive another item.
