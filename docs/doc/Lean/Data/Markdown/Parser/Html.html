    Raw HTML #

    The tag grammar of CommonMark §6.6, which is shared by raw inline HTML and the start condition of complete-tag HTML blocks, and the kinds of HTML block of CommonMark §4.6 with their end conditions.

                            inductive Lean.Markdown.HtmlBlockKind :
                            Type

                            The kind of an HTML block (CommonMark §4.6). The kind is determined by the start condition that the block's first line meets and selects the block's end condition.

                            • rawText : HtmlBlockKind

                              A pre, script, style, or textarea element. The block ends at a line that contains an end tag of any of these elements.

                            • comment : HtmlBlockKind

                              A comment. The block ends at a line that contains -->.

                            • processingInstruction : HtmlBlockKind

                              A processing instruction. The block ends at a line that contains ?>.

                            • declaration : HtmlBlockKind

                              A declaration. The block ends at a line that contains >.

                            • cdata : HtmlBlockKind

                              A CDATA section. The block ends at a line that contains ]]>.

                            • blockTag : HtmlBlockKind

                              An open or closing tag of a block-level element. The block ends before a blank line.

                            • completeTag : HtmlBlockKind

                              A complete open or closing tag alone on its line. The block ends before a blank line.
