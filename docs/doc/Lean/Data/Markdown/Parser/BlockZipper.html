    The In-Progress Zipper #

    While identifying the block structure of a document, lines are checked one at a time and added in order. A zipper-like structure makes it easy to see the surrounding block context and to modify it at the right-hand edge.

    inductive Lean.Markdown.OpenContainer (s : String.Slice) :
    Type

    A container that is currently open and may still receive child blocks.

    • blockquote {s : String.Slice} (markers : Array s.Subslice) : OpenContainer s

      A blockquote. markers accumulates the > markers from every continuation line that has been seen so far.

    • listItem {s : String.Slice} (list : OpenList s) (marker : s.Subslice) (contentColumn : Columns) : OpenContainer s

      A list item that is open, which makes it the last item of its list so far.

      • list is the list that the item belongs to, with the items that closed before this one.
      • marker is this item's bullet or ordered marker.
      • contentColumn is the column at which the item's content begins. Subsequent lines must be indented to at least this column to count as continuations of this item (CommonMark §5.2).

        inductive Lean.Markdown.OpenLeaf (s : String.Slice) :
        Type

        A leaf block that is currently open and may still accept additional source lines.

        • paragraph {s : String.Slice} (lines : Lines s) : OpenLeaf s

          An open paragraph that is being extended line by line. Closing the paragraph (because of a blank line, a new block opener, or the parent container closing) finalizes it as Block.Raw.paragraph.

        • fencedCode {s : String.Slice} (info : FenceInfo s) (openFence : s.Subslice) (lines : Array (VerbatimLine s)) : OpenLeaf s

          An open fenced code block. lines accumulates content lines until either a matching closing fence appears (yielding Block.Raw.fencedCode with closeFence? := some _) or the parent container closes at EOF (yielding closeFence? := none).

        • indentedCode {s : String.Slice} (lines pendingBlanks : Array (VerbatimLine s)) : OpenLeaf s

          An open indented code block.

          • lines are the content lines that have been committed so far, after the four columns of indentation.
          • pendingBlanks records blank lines that may belong to this block. They are promoted to lines when a subsequent indented line continues the block, and discarded when an unindented non-blank line closes the block. This matches CommonMark's rule that blank lines between indented chunks are part of the code block, but blank lines that follow the final chunk are not.
        • html {s : String.Slice} (kind : HtmlBlockKind) (lines : Array (VerbatimLine s)) : OpenLeaf s

          An open HTML block. kind selects the end condition, and lines accumulates the block's lines, starting with the one that met the start condition.

          structure Lean.Markdown.BlockZipper (s : String.Slice) :
          Type

          The block parsing state. Maintains the spine of currently-open containers plus an optional open leaf at the bottom.

          An empty spine means that only the document is open.

          Invariants:

          • If openLeaf? is some _, that leaf logically lives inside the deepest spine frame, or directly under the document if the spine is empty. Extending the leaf adds to its content, and closing the leaf pushes a Block.Raw onto that container's children.
          • A list contains only list items. An OpenList has items and nothing else, and every open list is either the list of an item frame or the pending list of the container around it. Children.push, the one operation that appends a block, finishes the pending list first.
          • document : Children s

            The children of the document root.

          • spine : Array (ZipperFrame s)

            Open containers below the document root, deepest last.

          • openLeaf? : Option (OpenLeaf s)

            An open leaf node, if one is present.

          • blankLineFloor? : Option Nat

            The position in spine of the outermost list that the most recent blank line could still make loose (CommonMark §5.3), or none when there is no such list or the next block has begun. A list is at the position of its open item's frame, or one past the deepest frame when it is the pending list of the deepest container.

            A blank line makes a list loose when the next block begins in one of the list's items. The lists it could make loose are therefore the open lists around it, from this position inward. The outermost of them is inside the nearest enclosing blockquote, because a blank line inside a blockquote separates blocks of the blockquote, not blocks of a list that contains the blockquote.

                      def Lean.Markdown.BlockZipper.recordBlankLine {s : String.Slice} (z : BlockZipper s) :
                      BlockZipper s

                      Records a blank line in the deepest open container.

                      A blank line between two blocks of a list item, or between two items, makes the list loose (CommonMark §5.3). Which list that is depends on where the next block begins, so the blank line is remembered until then, along with the outermost list it could affect. A blank line inside a blockquote affects only the blockquote's own content.
