    Inline Sources #

    The block parser carves a paragraph or heading into a sequence of source lines with the prefixes of enclosing containers already removed. The inline parser then reads that content as if it were a single contiguous string, while still producing subslices of s. InlineSource bundles the per-line subslices. Its constructor is private to prevent missing or double normalization.

    ofLines normalizes a block's lines as CommonMark §4.8 requires, and it is the only way to build an InlineSource.

    source
    structure Lean.Markdown.InlineSource (s : String.Slice) :
    Type

    The lines of a paragraph or setext heading, each as a subslice of the source. These lines form the input to the inline parser.

    Container prefixes such as > and leading spaces and tabs are not included in the lines. Each line except the last line of the block ends with its line ending, so the inline parser sees a line ending at each line boundary. The last line does not include its trailing whitespace.

    The lines are in source order and do not overlap.

    • lines : Array s.Subslice

      The lines, in source order.

    • nonempty : 0 < self.lines.size

      There is at least one line.

              def Lean.Markdown.InlineSource.ofLines {s : String.Slice} (lines : Lines s) :
              InlineSource s

              Constructs an InlineSource from the source lines of a paragraph. This implements the CommonMark §4.8 paragraph content normalization:

              • Leading spaces and tabs are removed from each line.
              • Each line except the last ends with the line ending that follows it in the source.
              • Trailing whitespace is removed from the last line.
