    Inline Cursor #

    InlineCursor steps through the lines of an InlineSource with drop1, skipping the gaps between lines that contain block markers and removed indentation. InlineContext is the reader state of the inline parser.

    source
    structure Lean.Markdown.InlineCursor (s : String.Slice) :
    Type

    A cursor into an InlineSource, analogous to a slice of a String. It consists of the current position, the end of the input, and the index of the line that contains the current position. A parser that is given a cursor reads the text from the current position to the end of the input and nothing else.

    • source : InlineSource s

      The source that is being tokenized.

    • line : Nat

      The index in source.lines of the line that contains startPos, or source.lines.size if it is not contained in any line.

    • startPos : s.Pos

      The position of the next character to read.

    • stopPos : s.Pos

      The position after the last character that the cursor may read.

      It is at most the end of the last line of source. It is before the end of the last line when the cursor is limited to a part of the source, such as the text between a pair of brackets.

                    Option (s.Subslice × InlineCursor s)
