    This module implements Unicode full case folding, as specified by the entries with status C and F in CaseFolding.txt of Unicode 18.0.0, for ASCII, the Latin-1 Supplement block, and the Greek and Coptic block, together with every character elsewhere whose folding consists of characters from those blocks, such as Ÿ, ẞ, the Kelvin sign, and the ligature ﬁ. Every other character folds to itself.

    def Lean.Markdown.pushCaseFolded (out : String) (c : Char) :
    String

    Appends the Unicode full case folding of c to out, for ASCII, the Latin-1 Supplement block, the Greek and Coptic block, and the other characters whose foldings are drawn from those blocks. Any other character is appended unchanged.

    Equations
    • Lean.Markdown.pushCaseFolded out c = if c.val < 181 then out.push c.toLower else match Lean.Markdown.fold?✝ c with | some folded => out ++ folded | none => out.push c

      def Lean.Markdown.caseFold (c : Char) :
      String

      The Unicode full case folding of c for the following characters:

      • ASCII
      • The Latin-1 Supplement block
      • The Greek and Coptic block
      • All other characters whose foldings are drawn from the above blocks:
        • Ÿ, ẞ, ſ
        • The Ohm, Kelvin, and Angstrom signs
        • The Latin ligatures ﬀ to ﬆ
        • The polytonic Greek letters with iota subscript.

      For characters not in the above set, caseFold is equivalent to String.singleton. In particular, letters with case in Cyrillic, the Latin Extended blocks (Turkish, Vietnamese, Polish, Czech, and others), Armenian, Georgian, Cherokee, Greek Extended (polytonic Greek), and the fullwidth and enclosed forms are not folded. This limitation may be lifted in the future.

      Equations
      • Lean.Markdown.caseFold c = Lean.Markdown.pushCaseFolded "" c
