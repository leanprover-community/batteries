    Text-Level Decoding #

    Backslash escapes and character references (CommonMark §2.4 and §2.5). The inline parser recognizes both as inline elements in paragraph text. Link destinations, link titles, and info strings are not parsed as inlines, so consumers decode them with decodeText.

    def Lean.Markdown.isAsciiControl (c : Char) :
    Bool

    Whether c is an ASCII control character (CommonMark §2.1), which is U+0000 to U+001F, or U+007F.

    Equations

      Bool

        def Lean.Markdown.characterReference? {s : String.Slice} (body : s.Subslice) :
        Option String

        Decodes the body of a character reference &body; (CommonMark §2.5), which is the text between & and ;.

        Named references are those of HTML. Decimal references (# followed by one to seven digits) and hexadecimal references (#x or #X followed by one to six hex digits) denote a code point; the code point zero, surrogates, and values above U+10FFFF decode to U+FFFD.
