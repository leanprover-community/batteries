                                                          inductive Lean.Markdown.Block.Raw (s : String.Slice) :
                                                          Type

                                                          A block of the source string s after the first pass, which determines the type and extent of every block but does not parse inline content. The content of a paragraph or heading is an InlineSource.

                                                          • paragraph {s : String.Slice} (content : InlineSource s) : Raw s

                                                            A paragraph, which is a sequence of consecutive non-blank lines that don't start any other kind of block.

                                                          • atxHeading {s : String.Slice} (level : Nat) (hashes : s.Subslice) (content : InlineSource s) (closeHashes? : Option s.Subslice) : Raw s

                                                            An ATX heading (the usual kind). level is the number of opening # characters, hashes is that opening sequence, and closeHashes? an optional closing sequence.

                                                          • setextHeading {s : String.Slice} (level : Nat) (content : InlineSource s) (underline : s.Subslice) : Raw s

                                                            A setext heading (CommonMark §4.3), which is one or more lines of paragraph text that are followed by an underline (=== for level 1, --- for level 2).

                                                          • fencedCode {s : String.Slice} (info : FenceInfo s) (openFence : s.Subslice) (closeFence? : Option s.Subslice) (lines : Array (VerbatimLine s)) : Raw s

                                                            A fenced code block. openFence/closeFence? are the fences. The closing fence is optional because an unterminated fenced code block spans the rest of the input. The content lines exclude up to info.openIndent columns of indentation.

                                                          • indentedCode {s : String.Slice} (lines : Array (VerbatimLine s)) : Raw s

                                                            An indented code block, which is a sequence of lines that are indented four or more columns. The verbatim lines exclude the four column indentation.

                                                          • html {s : String.Slice} (lines : Array (VerbatimLine s)) : Raw s

                                                            An HTML block (CommonMark §4.6), which has at least one line.

                                                          • blockquote {s : String.Slice} (markers : Array s.Subslice) (children : Array (Raw s)) : Raw s

                                                            A blockquote container. markers contains every > marker, in source order, and children contains the contained blocks.

                                                          • list {s : String.Slice} (kind : ListKind) (tight : Bool) (items : Array (Raw s)) : Raw s

                                                            A list container. All items are listItem blocks. tight reflects CommonMark's tight/loose distinction (§5.3). A tight list doesn't have blank lines between its items or between blocks within an item.

                                                          • listItem {s : String.Slice} (marker : s.Subslice) (children : Array (Raw s)) : Raw s

                                                            A list item. marker is the bullet or ordered marker, and children are the blocks that the item contains.

                                                          • linkRefDef {s : String.Slice} (m : RefDef s) : Raw s

                                                            A link reference definition, which is written [label]: destination "title" (the title is optional).

                                                          • thematicBreak {s : String.Slice} (line : s.Subslice) : Raw s

                                                            A thematic break (***, ---, or ___, optionally with interior spaces or tabs). line is the line's content from its first marker to its last.

                                                            def Lean.Markdown.ListKind.sameKind :
                                                            ListKind → ListKind → Bool

                                                            Whether two list kinds belong to the same list (that is, they have matching marker styles).

                                                            The starting number of an ordered list is irrelevant, so 1. and 5. are the same list kind. Bullets must use the exact same character, and ordered lists must use the same delimiter.

                                                            Equations
                                                            • (Lean.Markdown.ListKind.bullet a).sameKind (Lean.Markdown.ListKind.bullet b) = (a == b)
                                                            • (Lean.Markdown.ListKind.ordered a a_1).sameKind (Lean.Markdown.ListKind.ordered b b_1) = (a_1 == b_1)
                                                            • x✝¹.sameKind x✝ = false
