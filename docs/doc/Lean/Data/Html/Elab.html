        def Lean.Elab.Html.htmlCmd :
        ParserDescr

        #html e evaluates the HTML value e and renders it in the infoview. e must have a type supported by some #html elaborator: core Lean supports Lean.Html, whereas other packages may support custom HTML types.

        This command behaves similarly to #eval; e may also be a computation in any monad supported by #eval, e.g. IO Html.
