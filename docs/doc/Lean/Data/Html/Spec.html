          def Lean.Html.isVoidElement (tagName : String) :
          Bool

          Whether tagName (compared case-insensitively) names a void element.

          Void elements are those that cannot have any child nodes. These only have a start tag; end tags must not be specified. See https://html.spec.whatwg.org/dev/syntax.html#void-elements.

          Equations
          • Lean.Html.isVoidElement tagName = Lean.Html.voidElements✝.binSearchContains tagName.toLower fun (x1 x2 : String) => decide (x1 < x2)
