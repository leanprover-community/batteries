      def Lean.Html.characterReference? (ref : String) :
      Option String

      Looks up the string denoted by the body ref of an HTML character reference &ref;. Returns none when &ref; is not valid per the HTML standard.

      Named references (such as &amp;) must be listed in the HTML standard. Numeric references in decimal (&#123;) or hexadecimal (&#x7B;) notation must denote a Unicode scalar value that is not U+0000, U+000D, a noncharacter, or a control other than ASCII whitespace.
