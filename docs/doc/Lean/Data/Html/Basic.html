    inductive Lean.Html :
    Type

    HTML content, which may be either a single node or a sequence of sibling nodes.

    This type is optimized for convenient authoring of HTML documents. It is not formally related to the HTML DOM representation. It is analogous to React's Fragment.

    • element (tag : String) (attrs : Array (String × String)) (children : Html) : Html

      An element with the given tag name, attributes, and children.

    • text : String → Html

      Textual content.

      The characters &, <, and > are always escaped to HTML entities during rendering. Use raw in raw text elements (script and style) instead.

    • raw : String → Html

      Characters to be copied verbatim (and not escaped) during rendering.

    • seq : Array Html → Html

      A sequence of HTML values.
