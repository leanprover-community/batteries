                def Lean.Meta.Sym.DSimp.unfold (declNames : NameSet) :
                DSimproc

                Unfolds the applications of the definitions in declNames, like Meta.simp does for the definitions provided in simp [f]. A definition with smart unfolding support is unfolded only when its recursion argument reduces. Any other definition is unfolded only when applied to at least as many arguments as its number of leading lambdas.
