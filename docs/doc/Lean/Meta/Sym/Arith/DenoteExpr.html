              Denote a RingExpr whose variables index vars instead of the current ring's variables. Proof terms rename the variables of an expression to the compact range 0 .. n-1 of the variables it actually uses (see renameVars), and build an RArray context out of those n terms; the denotation of the renamed expression must use that same array.
