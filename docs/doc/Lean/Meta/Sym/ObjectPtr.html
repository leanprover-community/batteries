    structure Lean.Meta.Sym.ObjectPtr :
    Type

    Key for maps and sets that compares objects by address, a safe counterpart of Lean.Ptr. The key holds the object, so it stays alive and its address is not reused while the key exists. Equal values that are different objects are different keys.
