          structure Lean.Meta.Instances :
          Type
          • discrTree : InstanceTree
          • instanceNames : DeclKeyedMap Name InstanceEntry
          • erased : PHashSet Name
          • classChanges : PHashMap Name (List InstanceChange)

            For each class, the changes of its instances since the import, newest first. Type class resolution depends on the global instances only through the classes it consults, and records their changes instead of the generation of the whole table (RecordedDeps.instClassChanges). Recorded changes are only compared within the module that recorded them, i.e. against states with the same imported instances, so equal changes mean equal instances of the class. Restoring an earlier state (e.g. at the end of a section) restores the changes with it.

                        The global instance entries of a module, preprocessed and stored in its olean so that importing them does not require adding each entry (see registerSimpleScopedEnvExtensionWithSummaries).

                          The names and entries of the named entries owned by the module (see ImportedDeclKeyedMap.sortOwned).

                        • foreign : Array Name × Array InstanceEntry

                          The names and entries of the remaining named entries, in order.
