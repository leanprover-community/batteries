    This module provides the basic infrastructure for the CEGAR (Counter Example Guided Abstraction Refinement) solver.

    structure Lean.Meta.Tactic.BVDecide.CegarHyp :
    Type

    A hypothesis generated by the CEGAR refinement procedure.

    • hyp : Normalize.Hyp

      The Expr-level non-internalized hypothesis.

    • tacticProof : MetaM (TSyntax `Lean.Parser.Tactic.tacticSeq)

      A Syntax-level regular tactic proof for the hypothesis.

    • grindProof : MetaM (Option (TSyntax `Lean.Parser.Tactic.tacticSeq))

      A Syntax-level grind tactic proof for the hypothesis. If none we will use have : hyp and let grind modes' automation figure it out.
