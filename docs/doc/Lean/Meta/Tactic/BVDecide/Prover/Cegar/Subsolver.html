    This file implements a subsolver that is capable of incrementally processing QF_BV queries with pre-processing and incremental bitblasting. The solver is explicitly itself not a CEGAR loop with support for other theories but instead supposed to be used as a building block for other theories.

    source
    structure Lean.Meta.Tactic.BVDecide.Cegar.Subsolver :
    Type

    An incremental bitvector subsolver with a classic SMT push/pop/solve API. Supports incremental pre-processing and bitblasting but no theories beyond bitvectors.

    • reifyState : State

      Incremental reification state.

    • preProcessState : Grind.BVDecide.Caches

      Incremental caches for the rewrites in the pre-processor.

    • bvSolver : BitVecSolverState

      Incremental BitVEc solver state, this tracks the assumption levels.

    • mvar : MVarId

      The goal we are operating in.

    • ctx : TacticContext

      General bv_decide configuration.
