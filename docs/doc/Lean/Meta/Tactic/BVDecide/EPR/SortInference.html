    Lean.Meta.Tactic.BVDecide.EPR.EprProblem.inferSorts

    This module implements paradox style sort inference for the EPR problem. While detecting the potential sorts it also performs a monotonicity analysis. With this information it splits a sort up into their subsorts if the parent sort is monotone. This reduces the size of the sorts and in the process of doing that also the amount of required instances.

    Like paradox the algorithm performs a union-find throughout the problem. In the same sweep, it identifies non-monotone sorts by looking for positive occurences of equality. After all the information has been collected sorts are split up into their subsorts if their parent is non-monotone and all sort information relabeled accordingly.
