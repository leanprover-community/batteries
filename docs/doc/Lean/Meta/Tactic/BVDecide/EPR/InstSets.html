    This module implements a Z3 style analysis of instantiation sets for the MBQI procedure on BitVec encoded EPR problems. The procedure tracks the following sets:

    • For every predicate p for each argument position i a set of ground terms A_p_i
    • For every quantified variable x
      • a set of ground terms S_x, referred to as the instantiation set of x
      • a set of variables, called the "avoid set"
      • a set of ground terms, called the "exception set"

    In an initial step we analyze all existing quantifiers and visit their propositional atoms with polarity information:

    • x = t in:
      • negative polarity: adds the ground term t to S_x.
      • positive polarity: makes makes t an exception for x and puts every element of the sort into S_x.
    • x = y in:
      • negative polarity: merges all sets of x and y.
      • positive polarity: puts x and y into each other's avoid set.
    • p(.., x, ..) with x at position i merges the classes of x and A_p_i.

    After this initial analysis of the quantifiers we can inspect the ground instances (and continue to do so as the CEGAR loop works), here we are interested in correctly maintaining the A_p_i sets by inserting ground terms t occuring at position i in p. In particular, only the positions where where a variable occurs matter, the rest can be discarded.

    By continously updating the instantiation sets during the CEGAR loop we maintain candidate sets of interesting values for all variables in the form of the S_x sets. We use these to limit the search to interesting instances as opposed to always allowing any member of the sort in.

    The avoid and exception sets are used to build clever models of predicates that help this procedure.
