          structure Lean.Meta.Tactic.BVDecide.Atom :
          Type

          A BitVec atom.

          • width : Nat

            The width of the BitVec that is being abstracted.

          • atomNumber : Nat

            A unique numeric identifier for the atom.

          • synthetic : Bool

            Whether the atom is synthetic. The effect of this is that values for this atom are not considered for the counter example derivation. This is for example useful when we introduce an atom over an expression, together with additional lemmas that fully describe the behavior of the atom.

                        structure Lean.Meta.Tactic.BVDecide.State :
                        Type

                        The state of the reflection monad

                        • atoms : Std.HashMap Sym.ExprPtr Atom

                          The atoms encountered so far. Saved as a map from BitVec expressions to a (width, atomNumber) pair.

                        • atomsAssignmentExprCache : Option Expr

                          A cache for atomsAssignmentExpr. If it is none the cache is currently invalidated as new atoms have been added since it was last updated, if it is some it must be consistent with the atoms contained in atoms.

                        • atomsAssignmentMapCache : Option (Std.HashMap Nat (Nat × Expr × Bool))

                          The equivalent of atomsAssignmentExprCache but computed as a efficiently computable hashmap.

                        • evalsAtCache : Std.HashMap Sym.ExprPtr (Option Expr)

                          Cached calls to evalsAtAtoms of various reflection structures. Whenever atoms is modified this cache is invalidated as evalsAtAtoms relies on atoms.

                        • theoryState : TheoryState

                          State for theory solvers.
