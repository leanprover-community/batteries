    Lean.Meta.Grind.Arith.Cutsat.assertOrHull

    Hulls of disjunctions.

    Given a disjunction d₁ ∨ … ∨ dₙ that is True, where each dᵢ is a conjunction containing linear constraints, we assert the constraints lin + k ≤ 0 such that every dᵢ contains a conjunct implying lin + kᵢ ≤ 0 with k ≤ kᵢ. For example, (b = true ∧ y = x + 1) ∨ (b = false ∧ y = x + 2) implies x + 1 ≤ y and y ≤ x + 2.

    The hull avoids case splits that only matter for these bounds. For example, after n sequential if-then-else statements that add 1 or 2 to s, the bound s₀ + n ≤ sₙ follows from the hulls of the n disjunctions, while splitting on them produces 2ⁿ cases.
