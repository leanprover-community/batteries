    def Lean.Meta.Grind.propagateCharToNatUp :
    Propagator

    Propagates x.toNat = n when x is equal to a character literal c with code point n. The proof is congrArg Char.toNat (x = c) followed by Eq.refl n, whose type n = n is accepted for c.toNat = n by the kernel, which evaluates c.toNat.
