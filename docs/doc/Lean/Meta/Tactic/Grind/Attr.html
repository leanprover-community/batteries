    structure Lean.Meta.Grind.NormSymTheorems :
    Type

    The grind normalization theorems as Sym.simp theorem sets, the state of normSymExt. The [grind norm]/[grind unfold] attributes populate it together with normExt, so both normalizers see the same declarations.

    • pre : Sym.Simp.Theorems

      Theorems applied before visiting subterms ([grind norm ↓]).

    • post : Sym.Simp.Theorems

      Theorems applied after visiting subterms ([grind norm]), and the equational theorems of the declarations to unfold ([grind unfold]).

    • dsimp : Sym.DSimp.Decls

      The rfl-theorems of post and the declarations to unfold, for Sym.dsimp. grind needs dsimp in one place: the right-hand side of a generalized pattern (mkGeneralizedPatternEqProof) must stay definitionally equal to the term it replaces, e.g. Nat.succ x becomes x + 1.
