    def Lean.Meta.mkStringLitNeProof (s₁ s₂ : String) :
    MetaM Expr

    Builds a proof of String.ofList l₁ ≠ String.ofList l₂ for two distinct string literals.

    The proof is String.Internal.ofList_ne_ofList l₁ l₂ i (Eq.refl false) where i is the first position where the two strings differ. If one of them is a prefix of the other, i is the length of the shorter one.

    To check it, the kernel evaluates String.Internal.sameCharAt i l₁ l₂, which traverses the first i elements of the two lists simultaneously without comparing them, and then compares the characters at position i. It does not unfold String.decEq.

        def Lean.Meta.mkStringLitCodeProof (s : String) :
        Expr × Expr

        Builds a proof of String.Internal.code s = n for the string literal s, where n is the numeral stringLitCode s. Returns n and the proof.

        To check it, the kernel evaluates String.Internal.codeOfList on the list of characters of s.
