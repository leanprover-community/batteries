    structure Lean.CollectFVars.State :
    Type

    State of collectFVars. It can be threaded through several calls: subterms visited by earlier calls are not visited again. Use {} for an empty state, and State.ofFVarSet for a state that already contains free variables.

    • visited : Std.HashSet Lean.Meta.Sym.ExprPtr
    • fvarSet : FVarIdSet
    • fvarIds : Array FVarId

      State

      Returns a state that already contains fvarSet and fvarIds. Free variables in fvarSet are not collected again, so fvarSet can contain variables that are not in fvarIds.
