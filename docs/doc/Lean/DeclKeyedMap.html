    Maps keyed by declarations whose imported part is assembled from per-module data without inserting every entry: an entry about a constant declared in the module that added it is looked up in that module's sorted array, found using the imported constants, and only the remaining entries are kept in a hash map.

      structure Lean.ImportedDeclKeyedMap (κ α : Type) [BEq κ] [Hashable κ] :
      Type

      The imported part of a DeclKeyedMap.

      • consts : ImportedConsts ConstantInfo

        The imported constants, used to find the module declaring a constant.

      • ownedKeys : Array (Array κ)

        Per module index, the keys of the entries owned by the module (see isOwned), sorted.

      • ownedVals : Array (Array α)

        Per module index, the values of the owned entries, in the order of ownedKeys, or no values if they are all default.

      • foreign : PHashMap κ α

        The entries not owned by the module declaring their constant; they override owned entries.
