        def Lean.Parser.parseHeader (inputCtx : InputContext) (startPos : String.Pos.Raw := 0) :
        IO (TSyntax `Lean.Parser.Module.header × ModuleParserState × MessageLog)

        Parses a module header starting at startPos (default: 0), bounded by inputCtx.endPos.

        startPos must be a valid UTF-8 byte position in inputCtx.inputString at or before inputCtx.endPos. Compute it after any line-ending normalization by mkInputContext. Syntax offsets refer to this string; diagnostic positions use inputCtx.fileMap.

        Pass the returned parser state to parseCommand to continue parsing the same region.
