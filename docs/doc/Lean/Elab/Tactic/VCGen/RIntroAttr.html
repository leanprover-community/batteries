    The @[vcgen_rintro] attribute registers the rules by which vcgen destructures a binder while it introduces the binders of the target, like an rintro pattern fixed per binder type.

    A rule is a theorem whose conclusion is a ∀ telescope ending in an application of a parameter G. Its premises are the binders up to the last one that mentions G, and its conclusion is the rest. Take

    theorem List.forall_mem_cons_intro {G : α → Prop} (ha : G a) (hl : ∀ x, x ∈ l → G x) :
    ∀ x, x ∈ a :: l → G x

    with the conclusion ∀ x, x ∈ a :: l → G x. It turns the target ∀ x ∈ [a, b], G x into the goals G a and ∀ x ∈ [b], G x. The rules are keyed in a discrimination tree by their conclusion, whose ∀ binders become .arrow keys over the binder type and the body. At each binder of the target, vcgen applies the first matching rule in priority order as a backward rule to the remaining target, and otherwise introduces the binder.

    vcgen always uses the rule Prod.forall_intro.
