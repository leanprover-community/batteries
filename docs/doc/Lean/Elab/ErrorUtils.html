    Error-writing utilities #

    This module presents some convenience utilities for writing error and status messages in the Lean compiler.

    New operations on lists and strings are intended to operate through the dot-notation-respects-notation mechanism (https://juliahimmel.de/blog/an-underappreciated-lean-feature). To use n.toOrdinal in a module, first open Lean.Internal.ErrorUtils.

        def Lean.Internal.ErrorUtils.List.toOxford {α : Type u_1} [Append α] [HasOxfordStrings α] :
        List α → α

        Make an oxford-comma-separated list of strings.

        • ["eats"].toOxford == "eats"
        • ["eats", "shoots"].toOxford == "eats and shoots"
        • ["eats", "shoots", "leaves"] == "eats, shoots, and leaves"
        Equations
        • Lean.Internal.ErrorUtils.List.toOxford [] = Lean.Internal.ErrorUtils.HasOxfordStrings.emp
        • Lean.Internal.ErrorUtils.List.toOxford [a] = a
        • Lean.Internal.ErrorUtils.List.toOxford [a, b] = a ++ Lean.Internal.ErrorUtils.HasOxfordStrings.and ++ b
        • Lean.Internal.ErrorUtils.List.toOxford [a, b, c] = a ++ Lean.Internal.ErrorUtils.HasOxfordStrings.comma ++ b ++ Lean.Internal.ErrorUtils.HasOxfordStrings.commaAnd ++ c
        • Lean.Internal.ErrorUtils.List.toOxford (a :: as) = a ++ Lean.Internal.ErrorUtils.HasOxfordStrings.comma ++ Lean.Internal.ErrorUtils.List.toOxford as

            def Lean.Internal.ErrorUtils.Nat.plural {α : Sort u_1} [HasPluralDefaults α] (count : Nat) (singular : α := HasPluralDefaults.singular) (plural : α := HasPluralDefaults.plural singular) :
            α

            Give alternative forms of a string if the count is 1 or not.

            • (1).plural == ""
            • (2).plural == "s"
            • (1).plural "wug" == "wug"
            • (2).plural "wug" == "wugs"
            • (1).plural "it" "they" == "it"
            • (2).plural "it" "they" == "they"
            Equations
            • Lean.Internal.ErrorUtils.Nat.plural count singular plural = if count = 1 then singular else plural
