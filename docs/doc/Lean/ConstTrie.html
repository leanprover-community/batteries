    Prefix trees over constant names, stored per module in its olean parts and merged at import time.

    Each olean part carries a prefix tree over its constant names whose nodes live in the memory-mapped compacted region. finalizeImport merges the per-module trees into an ImportedConsts on demand, allocating fresh nodes only for name prefixes that occur in more than one module and sharing all single-module subtrees directly with the olean regions.

    inductive Lean.ConstTrie (α : Type) :
    Type

    A prefix tree over the constant names of a single module, keyed on name components. key is the full name prefix represented by a node. children is sorted by the (cached) hash of the child keys and searched by binary search; as all children extend key by one component, comparing that final component suffices to disambiguate equal hashes. Nodes are split by shape so that leaves and value-less nodes store no unused fields.

    • leaf {α : Type} (key : Name) (val : α) : ConstTrie α
    • inner {α : Type} (key : Name) (children : Array (ConstTrie α)) : ConstTrie α
    • node {α : Type} (key : Name) (val : α) (children : Array (ConstTrie α)) : ConstTrie α

                        inductive Lean.ImportedTree (α : Type) :
                        Type

                        Merged per-module constant prefix trees of all imported modules. Node keys and lookup work like in ConstTrie; subtrees whose prefix occurs in only a single module are borrowed directly from that module's (usually region-resident) tree.

                        • mod {α : Type} (modIdx : Nat) (tree : ConstTrie α) : ImportedTree α

                          A subtree containing entries of only a single module: the module's own tree.

                        • merged {α : Type} (key : Name) (entry? : Option (α × Nat)) (children : Array (ImportedTree α)) : ImportedTree α

                          A node whose prefix occurs in several modules, allocated at import time. entry? holds the value together with the index of the first module declaring it.

                        • lazy {α : Type} (key : Name) (entry? : Option (α × Nat)) (children : Thunk (Array (ImportedTree α))) : ImportedTree α

                          Like merged, but with the children computed on first access from the candidate subtrees sharing the prefix, one level at a time (see ImportedConsts.mergeModuleTreesLazy).
