    Ring identities by Kronecker substitution.

    Evaluating a polynomial with integer coefficients at the point xᵢ = X ^ (B ^ i) maps the monomial with packed code v to X ^ v. When B is larger than every degree and 2 * ‖p‖₁ < X, two polynomials with the same value are equal: the value written in base X has the coefficients as digits. So the kernel checks an identity a = b by evaluating a and b at the point, which is arithmetic on large natural numbers that it performs on literals directly, and by bounding the coefficients with Expr.majorant_k. The polynomials of a and b are not computed: they only appear in the proof (Expr.toPP_k).
