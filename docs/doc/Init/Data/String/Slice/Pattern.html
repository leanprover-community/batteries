            def String.Slice.splitToSubslice {ρ : Type} {σ : Slice → Type} (s : Slice) (pat : ρ) [Pattern.ToForwardSearcher pat σ] :
            Std.Iter s.Subslice

            Splits a slice at each subslice that matches the pattern pat.

            The subslices that matched the pattern are not included in any of the resulting subslices. If multiple subslices in a row match the pattern, the resulting list will contain empty subslices.

            This function is generic over all currently supported patterns.

            Examples:

            • ("coffee tea water".toSlice.splitToSubslice Char.isWhitespace).toStringList == ["coffee", "tea", "water"]

            • ("coffee tea water".toSlice.splitToSubslice ' ').toStringList == ["coffee", "tea", "water"]

            • ("coffee tea water".toSlice.splitToSubslice " tea ").toStringList == ["coffee", "water"]

            • ("ababababa".toSlice.splitToSubslice "aba").toStringList == ["", "b", "ba"]

            • ("baaab".toSlice.splitToSubslice "aa").toStringList == ["b", "ab"]

            Equations
            • s.splitToSubslice pat = { internalState := String.Slice.SplitIterator.operating s.startPos (String.Slice.Pattern.ToForwardSearcher.toSearcher pat s) }

                                                                    @[inline]
                                                                    def String.Slice.revAll {ρ : Type} (s : Slice) (pat : ρ) [Pattern.BackwardPattern pat] :
                                                                    Bool

                                                                    Checks whether a slice only consists of matches of the pattern pat, starting from the back of the string.

                                                                    Short-circuits at the first pattern mis-match.

                                                                    This function is generic over all currently supported patterns.

                                                                    For many types of patterns, this function can be expected to return the same result as Slice.all. If mismatches are expected to occur close to the end of the string, this function might be more efficient.

                                                                    For some types of patterns, this function will return a different result than Slice.all. Consider, for example, a pattern that matches the longest string at the given position that matches the regular expression "a|aa|ab". Then, given the input string "aab", performing Slice.all will greedily match the prefix "aa" and then get stuck on the remainder "b", causing it to return false. On the other hand, Slice.revAll will match the suffix "ab" and then match the remainder "a", so it will return true.

                                                                    Examples:

                                                                    • "brown".toSlice.revAll Char.isLower = true

                                                                    • "brown and orange".toSlice.revAll Char.isLower = false

                                                                    • "aaaaaa".toSlice.revAll 'a' = true

                                                                    • "aaaaaa".toSlice.revAll "aa" = true

                                                                    • "aaaaaaa".toSlice.revAll "aa" = false

                                                                    Equations
                                                                    • s.revAll pat = (s.skipSuffixWhile pat == s.startPos)
