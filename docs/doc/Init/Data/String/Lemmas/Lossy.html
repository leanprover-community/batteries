    fromUTF8Lossy (l ++ b) = singleton '�' ++ fromUTF8Lossy b

    If decoding l ++ b fails at the first byte, all other bytes of l are continuation bytes and b does not start with a continuation byte, then fromUTF8Lossy replaces l with a single � and continues with b.

    The bytes 0xED x y with 0xA0 ≤ x < 0xC0 and 0x80 ≤ y < 0xC0 would encode a surrogate code point (U+D800 to U+DFFF), so fromUTF8Lossy replaces them with a single �, provided that b does not start with a continuation byte.
