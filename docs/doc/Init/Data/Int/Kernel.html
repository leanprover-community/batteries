    Kernel-reduction variants of Int arithmetic, written with Int.rec, Bool.rec, and Nat operations that the kernel evaluates on literals, together with proofs that they agree with the standard operations. They avoid match and explicit recursion, which the kernel unfolds slowly. Used in certificates that the kernel checks by evaluation, such as those of lia.
