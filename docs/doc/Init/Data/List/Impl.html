    Tail recursive implementations for List definitions. #

    Many of the proofs require theorems about Array, so these are in a separate file to minimize imports.

    The definitions replaced here are noncomputable, so compiled code using them must import this file.

    Basic List operations. #

    The following operations are already tail-recursive, and do not need @[csimp] replacements: get, foldl, beq, isEqv, reverse, elem (and hence contains), drop, dropWhile, partition, isPrefixOf, isPrefixOf?, find?, findSome?, lookup, any (and hence or), all (and hence and) , range, eraseDups, eraseReps, span, splitBy.

    The following operations are still missing @[csimp] replacements: concat, zipWithAll.

    The following operations are not recursive to begin with (or are defined in terms of recursive primitives): isEmpty, isSuffixOf, isSuffixOf?, insert, enum, min?, max?, min, max and removeAll.

    The following operations were already given @[csimp] replacements in Init/Data/List/Basic.lean: length, map, filter, replicate, leftPad, range'.

    The following operations are given @[csimp] replacements below: set, filterMap, foldr, append, bind, join, take, takeWhile, dropLast, replace, modify, insertIdx, erase, eraseIdx, zipWith, unzip, enumFrom, intersperse and intercalate.

    The following definitions use the operations above. They are given @[csimp] replacements below with the same definition, which is compiled using the replacements of those operations: sum, prod, foldrRecOn, extract, rotateLeft, rotateRight, isPerm and zip.
